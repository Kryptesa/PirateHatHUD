# Embedded assets

`icon.png` is the default treasure chest HUD icon embedded as RCDATA resource 101.
An optional `PirateHatHUD_treasure.png` next to the ASI overrides it.

`treasure.wav` is embedded as RCDATA resource 102. It is mono 16-bit PCM at 44.1 kHz.
An optional `PirateHatHUD_treasure.wav` next to the ASI overrides it. Neither asset
is copied into the distribution as a standalone file.

See `THIRD_PARTY_NOTICES.md` for the sound source and attribution.
